# Legal Toolkit for Outlook

This repository hosts the Legal Toolkit Outlook add-in as a static website (GitHub Pages).

**To install, open the `install.html` page of this site.**

The add-in runs entirely inside Outlook. It has no server, collects no data, and sends no email content anywhere. Firm settings are in `config.js`.

## House Style add-in

The House Style add-in (Ali Sharif Zu'bi) is in the `house-style` folder. To install it, add `house-style/manifest.xml` as a custom add-in in Outlook.
